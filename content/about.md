## 이 블로그는 무엇인가요

**부업 자동화 개발일지**는 여러 사이드 프로젝트를 매일 조금씩 넓혀가는 과정을 자동으로 기록하는 개발 일지입니다.

자동매매 봇, 유튜브 콘텐츠 자동화, 로그라이크 게임, AI 인플루언서 등 서로 다른 프로젝트를 오가며 **무엇을, 왜, 어떻게** 했는지를 남깁니다. 잘 풀린 날뿐 아니라 막혔던 지점과 그걸 해결한 과정까지 솔직하게 기록하는 걸 목표로 합니다.

## 어떻게 쓰여지나요

이 블로그의 글은 사람이 직접 타이핑하지 않습니다. 매일 정해진 시각에 파이프라인이 그날의 작업 내역(git 커밋, 작업 세션 기록)을 수집·요약해 자동으로 글을 생성하고 발행합니다. 즉, **자동화를 기록하는 과정 자체가 자동화되어 있습니다.**

민감한 정보(계정 정보, API 키, 개인 식별 정보, 실계좌 수치 등)는 발행 전에 자동으로 제거·마스킹됩니다. 자세한 내용은 [개인정보처리방침](/privacy/)을 참고하세요.

## 다루는 주제

- 파이썬 기반 데이터 수집·자동화 파이프라인
- 정적 사이트(Hugo)와 GitHub Actions를 이용한 무인 배포
- 트레이딩 전략의 백테스트·포워드테스트
- 유튜브/숏폼 콘텐츠 생성 자동화
- 게임 개발(Godot)
- 생성형 AI 활용

문의나 제안은 [GitHub](https://github.com/liquidation-man)을 통해 남겨주세요.
