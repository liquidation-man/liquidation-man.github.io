티스토리 자동 발행 파이프라인에서 발생하던 빈 글 발행 문제, 편집기 로딩 시점 미동기화, 세션 만료 사전 감지 부재, 하단 링크 누락 문제를 고쳤다. 웹 편집기의 상태 변화를 단순 입력 명령 직후 판단하지 않고 저장 결과까지 직접 검증하도록 바꿨으며, 세션 확인과 하단 전자책 링크 삽입을 자동화 과정에 명시적으로 추가했다. 이 변경으로 자동 발행 과정에서 내용이 비어 있는 채 글로 올려지거나 세션 끊김으로 작업이 실패하는 현상을 차단했다.

## 편집기 로딩 전에 본문이 입력되어 빈 글이 저장되던 문제

티스토리 자동 발행 과정에서 본문이 비어 있는 상태로 게시물 두 편이 나가는 문제가 발생했다. 원인을 확인해보니 백그라운드 러너 환경에서 웹 편집기가 완전히 준비되기 전에 본문 데이터를 주입하려고 시도했고, 본문이 들어갔다고 간주한 채 즉시 저장 및 발행을 진행했기 때문이었다. 입력 스크립트 실행과 실제 에디터 내 데이터 안착 사이의 시차가 존재하여, 시스템은 정상 입력을 보고했으나 실제 저장소에는 빈 본문만 남는 현상이었다.

단순히 본문 주입 명령을 보냈다고 성공으로 간주하는 방식을 버리고, 편집기가 완전히 초기화될 때까지 대기한 뒤 저장된 본문 컨텐츠를 다시 읽어 실제로 내용이 들어갔는지 검증하도록 고쳤다. 편집기 준비 완료 이벤트를 기다리고 저장 후 재확인하는 단계를 넣었기 때문에 발행 처리 시간은 이전보다 조금 더 늘어났다. 하지만 속도를 아주 조금 손해 보는 대신 내용이 날아간 빈 글이 외부로 발행되는 오동작을 확실하게 차단하는 트레이드오프를 선택했다.

## 세션 만료를 뒤늦게 알고 전자책 링크가 빠져 있던 문제

자동 발행 실행 도중 세션이 이미 만료되어 있음에도 발행 절차를 모두 진행한 뒤에야 오류가 발생하는 문제가 있었다. 만료된 상태에서 전체 과정을 수행하다 보니 불필요한 작업 시도가 반복되고 세션 문제 발생 시점을 정확히 파악하기 어려웠다. 또한 티스토리 채널로 발행되는 글 하단에 전자책 안내 링크가 포함되지 않는 누락 현상도 함께 발견되어, 채널 간 콘텐츠 구성의 불일치가 발생하고 있었다.

글을 작성하기 위해 편집기에 진입하기 전 세션 유효성을 미리 검사하는 단계를 추가했고, 발행 템플릿 하단에 전자책 링크를 자동으로 붙이도록 변경했다. 사전 검증을 위한 별도의 요청이 추가되면서 약간의 네트워크 호출이 늘어났고 템플릿 처리 로직도 커졌지만, 만료된 세션으로 무의미하게 작업을 이어가는 자원 낭비를 막고 글마다 필요한 링크가 빠짐없이 들어가도록 보장할 수 있게 되었다. 이제 세션이 끊겨 있으면 작업을 즉시 중단하고 알림을 발생시키며, 발행되는 모든 글에는 하단 링크가 빠짐없이 들어간다.

이번 작업으로 자동 발행의 안정성과 콘텐츠 완성도를 높였으나, 세션이 만료되었을 때 스스로 다시 인증을 갱신하는 자동 재인증 흐름까지는 구현하지 못했다. 현재는 세션 만료를 사전에 차단하고 중단하는 데 그치고 있어, 향후 세션이 만료되었을 때 작업자가 개입하지 않고도 인증을 복구하는 구조를 고민해야 한다.
